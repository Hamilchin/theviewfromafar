How is this better than TDMPC2?
TDMPC2 uses representations that 1. Need a reward signal to train, and 2. are task-specific. This means relearning dynamics for each new task, and not having any offline transfer (all data has to be from an environment with reward). This means it is not as general, and doesn't get the added "foundation-style" knowledge transfer.
